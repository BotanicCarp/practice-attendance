# PracticeAttendance — локальная стартовая версия

Сайт для учёта посещаемости практикантов: личные аккаунты, проверка геолокации, фото пропуска, журнал администратора и CSV-экспорт.

## Важно
Это стартовая версия для локального тестирования, а не готовый к публикации в интернете сервис. Перед публичным запуском необходимо добавить/проверить CSRF-защиту всех форм, ограничение частоты входа, HTTPS, резервное копирование, политику обработки персональных данных и корректное локальное время. Геолокацию можно подделать; она не доказывает личность человека. Дата посещения сейчас рассчитывается по дате сервера (UTC), поэтому до эксплуатации настройте рабочий часовой пояс и правила опоздания.

## Требования
- Python 3.11+
- VS Code (не обязателен)
- Для локального запуска PostgreSQL не требуется: используется SQLite.
- Для production рекомендуется PostgreSQL и приватное файловое хранилище.

## Установка на Windows / VS Code

1. Распакуйте папку проекта.
2. Откройте папку `PracticeAttendance` в VS Code.
3. В терминале PowerShell выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

4. Откройте `.env` и замените:
   - `SECRET_KEY` на длинную случайную строку.
   - `INITIAL_ADMIN_PASSWORD` на уникальный пароль минимум из 10 символов.
   - Внесите координаты объекта в `PRACTICE_LAT` и `PRACTICE_LON`.
   - При необходимости измените `PRACTICE_RADIUS_M`.

5. Запустите:

```powershell
python app.py
```

6. Откройте `http://127.0.0.1:5000`.

## Первый вход администратора
Логин и пароль задаются в `.env` локально или в Environment Variables Vercel:
- `INITIAL_ADMIN_USERNAME`
- `INITIAL_ADMIN_PASSWORD`
- `INITIAL_ADMIN_NAME`

При старте приложения настроенная учётная запись администратора создаётся или синхронизируется с указанными переменными. Не используйте общий или опубликованный пароль.

## Создание практикантов
Войдите как администратор → «Практиканты». Заполните ФИО, логин, временный пароль, группу, номер пропуска и выберите учебное заведение из выпадающего списка. Номер пропуска должен содержать только цифры и быть уникальным. На физическом пропуске предполагается только цифровой номер — без фотографии человека и ФИО. Для ранее созданных аккаунтов используйте действие «Изменить данные», чтобы заполнить учебное заведение и номер пропуска. Смена пароля пользователем пока не реализована, поэтому выдавайте уникальные временные пароли безопасным способом.

## Геолокация
- В браузере нажмите разрешить доступ к местоположению.
- В `.env` должны быть заполнены координаты объекта.
- Для локального теста браузер разрешает геолокацию на `localhost`.
- В интернете необходим HTTPS.
- Фото пропуска принимаются JPG, JPEG, PNG, WEBP до 5 МБ.
- Фотографии пропусков доступны в административной папке выбранного дня; карточка показывает ФИО практиканта, номер пропуска, учебное заведение и время отметки.
- На Vercel фотографии сейчас попадают во временный каталог `/tmp`; это не постоянное хранилище. До реальной эксплуатации подключите приватное объектное хранилище.

## Что пока не реализовано
- Отдельное управление расписанием и правилами опозданий.
- Смена пароля пользователем.
- Восстановление пароля.
- Автоматические уведомления.
- Автоматическое распознавание фотографии пропуска.
- Проверка подмены GPS.
- Полноценный аудит всех административных действий.
- Настройка часового пояса для отчётности.
- Перенос фотографий из временного каталога Vercel в приватное постоянное хранилище.
- Переход с временной SQLite на PostgreSQL для production.
- Excel `.xlsx` экспорт; сейчас есть CSV, открываемый в Excel.

## Координаты места практики
В Windows можно получить координаты через карту, но проверяйте точность вручную. Не публикуйте координаты объекта, если это чувствительная информация.


**Структура проекта:** все файлы проекта расположены в корне репозитория, без вложенных папок. При запуске приложение добавляет новые колонки `educational_institution` и `pass_number` к существующей таблице пользователей, не удаляя старые записи.
