# Подготовка к GitHub и Vercel

## Важно до публикации

Этот пакет очищен от `.env`, `.venv`, локальной SQLite-базы и загруженных фотографий. Не загружайте секреты и реальные данные практикантов в GitHub.

Vercel поддерживает Flask и автоматически обнаруживает приложение в `app.py`, но файловая система функций в основном доступна только для чтения, а `/tmp` временный. Поэтому текущая локальная SQLite-база и каталог `private_uploads` не подходят для постоянного хранения на Vercel.

До использования с реальными практикантами необходимо подключить постоянную PostgreSQL-базу и приватное объектное хранилище фотографий, а затем адаптировать код для записи/чтения фотографий через это хранилище. Не разворачивайте текущую версию как рабочую систему для персональных данных до этой доработки.

## GitHub
1. Создайте отдельный новый репозиторий, например `practice-attendance`. Не используйте репозиторий DrivePro.
2. Загрузите содержимое этой папки в корень нового репозитория.
3. Убедитесь, что в репозитории нет `.env`, `.venv`, `attendance.db` и фотографий из `private_uploads`.

## Vercel
После настройки постоянной базы данных и приватного хранилища подключите отдельный проект через Import Git Repository. Vercel умеет автоматически обнаруживать Flask-приложение. Настройки подключения и секреты добавляйте в Project Settings → Environment Variables, не в Git.


**Структура проекта:** все файлы проекта расположены в корне репозитория, без вложенных папок.
